2️⃣  CONFIGURAR (ÚNICO PASSO!)
─────────────────────────────────────────────────────────────────────────────
Edite: src/config/api.config.js

Encontre:

❓ TROUBLESHOOTING RÁPIDO
═══════════════════════════════════════════════════════════════════════════

Problema: "Host Unreachable"
Solução:
  1. npm run test:api
  2. Verifique: netstat -ano | findstr :3000
  3. Firewall: Settings → Windows Defender Firewall → Permitir
  4. IP: Confira em api.config.js

Problema: "ERR_CLEARTEXT_NOT_PERMITTED" (Android 9+)
Solução:
  1. Edite: android/app/src/debug/AndroidManifest.xml
  2. Adicione: android:usesCleartextTraffic="true"

Problema: Device físico não conecta
Solução:
  1. Device e PC na mesma rede WiFi?
  2. IP do Windows está correto em api.config.js?
  3. Execute: npm run test:api
