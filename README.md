# Flashcards

**Flashcards** é um aplicativo mobile em desenvolvimento para criação, organização e revisão de decks de flashcards. O projeto oferece uma experiência prática de estudo, permitindo acompanhar o conteúdo aprendido e organizar sessões de revisão de acordo com a dificuldade e a importância de cada cartão.

## Sobre o projeto

O objetivo do aplicativo é facilitar o estudo por meio de flashcards, oferecendo recursos para:

- Criar e organizar conjuntos de cartões;
- Estudar cartas separadamente por deck;
- Avaliar o nível de conhecimento durante as revisões;
- Identificar e revisar cartões atrasados ou difíceis;
- Definir prioridades e marcar cartões como importantes;
- Criar ciclos de estudo personalizados por conjunto ou tag;
- Pesquisar conteúdo entre decks;
- Importar e exportar dados;
- Acompanhar estatísticas relacionadas ao estudo;
- Personalizar configurações de acordo com as preferências do usuário.

## Como funciona

Cada deck pode conter vários flashcards, com uma pergunta ou informação na frente e a resposta no verso. Durante uma revisão, o usuário pode avaliar o conhecimento em cada cartão, permitindo organizar as próximas sessões e priorizar conteúdos que precisam de mais atenção.

O aplicativo também disponibiliza ciclos de estudo com regras personalizáveis. É possível selecionar cartas atrasadas, prioritárias, importantes, fixas por conjunto ou relacionadas a determinadas tags.

## Tecnologias utilizadas

- React Native
- Expo
- TypeScript
- React Navigation
- Drizzle ORM
- expo-sqlite
- SQLite

Os dados são armazenados localmente no dispositivo. Atualmente, não é apresentada uma sincronização em nuvem ou com servidores externos.

## Funcionalidades disponíveis

- Gerenciamento de decks e cartões;
- Busca e organização de conjuntos;
- Revisão individual ou por ciclo de estudo;
- Classificação da dificuldade dos cartões;
- Configuração de prioridades e tags;
- Visualização de estatísticas;
- Exportação e importação de conteúdo;
- Preferências e configurações personalizáveis;
- Síntese de voz para auxiliar durante o estudo.

## Estado do projeto

Este projeto está em desenvolvimento ativo. Algumas funcionalidades podem sofrer alterações à medida que a experiência de uso e a arquitetura são aperfeiçoadas.
